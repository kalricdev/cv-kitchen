# ATS document checklist

Use the employer's requested file format. DOCX and text-based PDF are common
submission formats; a PDF containing only scanned images is not equivalent to
a text-based document.

## Structure and content

- Use a single column and conventional section headings in the document language.
- Keep letter spacing normal; avoid spaced-out words and headings.
- Put the name and contact details in body text, not document headers or footers.
- Keep employer names, job titles, and dates explicit and consistent.
- Use ordinary bullets and real selectable text.
- Use burnt-orange accents (#c2410c) sparingly with readable dark body text on a
  light background when document tools permit; honor required styling first.
- Include Projects and Certifications & Diplomas only when relevant, verified
  entries exist. Preserve exact credential names and distinguish course diplomas
  from academic degrees. Omit empty sections.
- Avoid tables, text boxes, icons, photos, charts, and decorative graphics.
- Include job terminology only for verified experience or skills. Avoid hidden
  keywords, repetition for its own sake, unsupported claims, and fabricated scores.
- Resolve placeholders and unsupported credentials before treating the CV as final.

These choices address known parser failure modes. Greenhouse lists graphics,
photos, tables, headers, footers, and text boxes among causes of unsuccessful
parsing in its [official parsing guidance](https://support.greenhouse.io/hc/en-us/articles/200989175-Unsuccessful-resume-parse).
Other hiring systems can behave differently; no layout guarantees universal
acceptance.

## Check the delivered file

1. Open the file and inspect each page for clipping, misplaced headings, blank
   pages, unreadable text, and unexpected page breaks.
2. Extract text when tools permit, or copy the document text into a plain-text
   editor. Compare it with the approved CV: names, contact details, dates, titles,
   bullets, and reading order should survive.
3. Confirm that the PDF contains text rather than only an image. Review visible
   link labels and destinations.
4. Check that the submission format and filename match the employer's request.
5. Report precisely which checks ran. Mark unavailable extraction, visual review,
   or link checks as unverified.

A successful extraction check is useful evidence of readability; it cannot prove
truthfulness, completeness, ranking, or acceptance by an employer's ATS.
